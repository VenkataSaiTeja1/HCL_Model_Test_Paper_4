# HCL Model Test Paper 4

A self-contained React application for HCL Campus Drive practice with **Model Test Paper 4** (30 Section A MCQs across Quantitative Aptitude, Logical Reasoning, and Computer Fundamentals + 1 Section B Coding Problem with Java & Python solutions and test cases).

---

## 🛠️ Features & Setup

1. **Model Test Paper 4**:
   - 30 MCQs across Quantitative Aptitude, Logical Reasoning, and Computer Fundamentals.
   - Section B Coding Problem: Warehouse Robot Route (Breadth-first search on a grid) with full Java & Python solutions and extra test cases.
   - Interactive Question Bank, timed Mock Test mode, and Coding Round practice.
2. **Configured for Vercel**:
   - Built with Vite + React 18.
   - Single Page Application (SPA) routing configuration (`vercel.json`).
3. **Overview Tab Removed**:
   - Streamlined directly to practice tabs (Question Bank, Mock Test, Coding Round).
